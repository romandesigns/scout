# Scout v6.5.1 — Windows validation portability hotfix

This patch does **not** change Scout detection, scoring, ranking, lifecycle, or notification intelligence.

It addresses two Windows-only validation issues discovered after v6.5.0:

- SQLite handles are now explicitly closed through `Store.close()` / context-manager support, including app shutdown and replay completion. Windows cannot delete temporary SQLite files while connections remain open.
- `RustPerceptionBridge` exposes its process argument list while preserving the production default `--stream`. The fake bridge regression test now launches its Python fixture through `sys.executable`, which is portable on Windows instead of relying on a Unix shebang executable.

The v6.4.13 frozen intelligence architecture remains unchanged.
