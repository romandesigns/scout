# Scout Optimization Milestones

One file per achieved milestone, newest last. "Achieved" means measured/validated, not just
attempted — a tested-and-disproved experiment is still a milestone (it's real knowledge), a
designed-but-unrun idea is not yet one.

Naming: `YYYY-MM-DD-NNN-short-slug.md`, numbered sequentially within a day.

Nothing in this folder implies anything was shipped to production. See `SESSION-STATE.md` at
the repo root for the standing rule: no commit/push/deploy without the user's review.
