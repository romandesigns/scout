# Project documentation

- `CHANGELOG-UNRELEASED.md` is the consolidated, code-backed record of current
  working-tree changes, validation, and remaining evidence requirements.
- `guides/` contains operational, validation, deployment, replay, and build guides.
- `implementation-history/` contains version-specific implementation notes and forensic findings.

The repository root is reserved for current entry-point documents: `README.md`, `CHANGELOG.md`, and `SESSION-STATE.md`.
