# Scout v6.7.0 — 24H Stocks Panel

Adds a dedicated 24H Stocks category/panel backed by empirically BOATS-verified symbols.

Design invariants:
- A ticker enters the 24H panel only after Scout receives a BOATS trade for it in the current trading session.
- BOATS trades already use the exact same `_handle_trade -> _metrics -> _maybe_emit` path, Rust bridge, catalyst association, quality grading, stage classification, continuation gates, outcome tracking, and notification dispatcher as SIP trades.
- The panel is therefore a category/observability view, not a second or weaker detector.
- Once verified by BOATS for the session, the ticker remains in the 24H panel while regular-session SIP updates continue, preserving one continuous opportunity lifecycle.
- 24H verification resets with Scout's 8 PM ET trading-session boundary.

The panel exposes current price, stage, A/B/C rank, quality score, 5s/15s velocity, RVOL, feed, and last BOATS activity.
