# Scout v6.6.8 — Targeted Late-Stage Continuation Guard

v6.6.8 preserves v6.6.7 EARLY/BREAKOUT behavior and the canonical anti-late boundary.

Production audit evidence motivating this release:
- v6.6.7 late rate remained 0% in the matured actionable cohort.
- EARLY and BREAKOUT 5-minute average returns were slightly positive.
- The tiny IGNITION and HALT_PRESSURE cohorts showed materially worse adverse excursion.
- Promotion traces still demonstrated that HALT_PRESSURE could be promoted while marked late-risk.

Changes:
- HALT_PRESSURE now uses the same canonical fresh-promotion late-risk suppression as SURGE/BREAKOUT/IGNITION.
- Fresh IGNITION requires positive immediate 5-second continuation instead of relying only on older 15s/30s momentum.
- HALT_PRESSURE requires both immediate 5-second and 15-second continuation and is blocked when late-risk.
- EARLY, BREAKOUT, REARM, VWAP_RECLAIM, and EMA_RECLAIM qualification is unchanged.
- Promotion trace now records the late-stage continuation decision for promoted IGNITION/HALT_PRESSURE.
- Detection-quality audit v5 is bundled so 5-minute matured and 15-minute final performance remain separately visible.

This is a quality/risk-control optimization, not a guarantee of profitability.
