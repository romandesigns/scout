# Scout v6.5.3 implementation

## Scope

This release hardens the v6.5.2 workstation before smoke testing. It intentionally does not change detector thresholds or Rust/Python signal semantics.

## Symbol-switch latency

- First live chart request starts immediately on ticker selection.
- A bounded 4-second client snapshot cache gives instant warm revisits.
- Identical concurrent requests share one promise instead of multiplying backend work across panes.
- Selection prefetch starts from the shared Scout selection path.
- Configured live clients no longer render deterministic demo candles while awaiting the API.

## Workspace behavior

- Four-pane initialization uses unique tickers.
- Selecting a ticker already open focuses that pane instead of creating a duplicate.
- A new ticker replaces the active unpinned pane; if it is pinned, Scout chooses the first unpinned pane.

## Chart communication

- Formation regions remain visible without a persistent formation text label.
- Permanent gesture-instruction text is removed from the plotting area.
- Cold symbols display an explicit loading state rather than stale prior-symbol data.

## Validation target

Run Python, Rust, UI primitive audit, TypeScript/Next production build, then smoke-test live symbol switching, pane focus, mobile Inspector navigation, chart gestures, and PWA/desktop notification behavior.
