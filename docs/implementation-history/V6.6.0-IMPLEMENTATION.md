# Scout v6.6.0 — Promotion Gate Trace

This release instruments the Developing -> actionable promotion path. It does not loosen or tighten detection thresholds.

Each PRE_IGNITION / ACTIVITY_WATCH finding now carries a `candidate_profile.promotion_trace` object with gate outcomes, blocker names, candidate age, extension, and late-risk state. Actionable findings carry the same trace plus the measured delay from first-leg awareness when available.

Use `validate-promotion-trace.ps1` after production has accumulated new findings to see which gates most often prevent promotion and whether those blockers persist until the setup is already extended.
