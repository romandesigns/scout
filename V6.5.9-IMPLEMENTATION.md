# Scout v6.5.9

## Purpose

v6.5.9 corrects the forward detection-quality evaluator. It does not retune Scout's detection rules.

## Changes

- Strict A/B actionable cohort by default.
- Optional Developing/C cohort via `-IncludeDeveloping`.
- `historical=1` snapshot mode forces a detection-centered historical candle window so 5m/15m forward data are available after maturity.
- Evaluation coverage is explicit: `UNMATURED`, `PROVISIONAL_5M`, and final 15-minute maturity.
- Final signal labels are not produced when the required data are incomplete.
- Persisted outcome metrics are included as a cross-check against recomputed candles.
- Stage-by-stage and cohort summaries are emitted in JSON/CSV and console output.
